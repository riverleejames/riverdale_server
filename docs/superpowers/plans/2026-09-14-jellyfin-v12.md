# Jellyfin v12 Cutover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Jellyfin 12 as the live media server with Seerr/Maintainerr on Jellyfin, Plex retained behind compose profile `plex` for rollback.

**Architecture:** LinuxServer Jellyfin on `riverdale_network` + Traefik `jellyfin.lan`; WatchState one-way Plex→Jellyfin; dated config snapshot; Plex service unchanged except `profiles: [plex]`.

**Tech Stack:** Docker Compose, LinuxServer Jellyfin, WatchState, Traefik, Seerr, Maintainerr

## Global Constraints

- Image: `lscr.io/linuxserver/jellyfin:latest` (v12)
- Do not delete or rewrite Plex config/media
- WatchState host port must not be 8080 (Traefik dashboard)
- Plex stays running until WatchState import has run
- No secrets in git; do not commit `.env`
- Conventional commits (`feat`/`docs`/`chore`)
